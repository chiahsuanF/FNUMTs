## Depencency
Dependencies for fnumts:

* python3
* pysam(version 0.22.0)
* argparse(version 1.4.0)
* pandas(version 2.1.1)
* bwa(version 0.7.17)
* bsalign(version 1.2.1)
* snpEff(version)
  
## Installation

### Conda
```
conda create -n fnumts
conda activate fnumts
conda install -c bioconda fnumts
```

```
git clone
```
